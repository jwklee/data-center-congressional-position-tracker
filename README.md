# Congressional Data Center Position Tracker

This repository contains the rendered public website for the Congressional
Data Center Position Tracker.

- [Combined tracker](https://jwklee.github.io/data-center-congressional-position-tracker/congressional_position_tracker.html)
- [Tracked members in the 2026 election](https://jwklee.github.io/data-center-congressional-position-tracker/2026_elections.html)
- [2026 House race comparisons](https://jwklee.github.io/data-center-congressional-position-tracker/2026_house_races.html)
- [Methods and scope](https://jwklee.github.io/data-center-congressional-position-tracker/methods.html)

Release 0.5.0 covers attributable actions through October 22, 2026. It displays
the 535-person analytical cohort plus 11 House successors elected during the
119th Congress. Research records, archived source copies, build scripts, and the
internal analysis page are maintained privately.

Citation metadata is available in [CITATION.cff](CITATION.cff), and applicable
terms are described in [LICENSE.md](LICENSE.md).
